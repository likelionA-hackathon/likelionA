## 3. 환경 세팅 (10분)

레포: <https://github.com/likelionA-hackathon/likelionA>

> **먼저 Org 초대 메일부터 수락해주세요.** 수락 안 하시면 push가 안 됩니다.

터미널에서 순서대로:

```bash
git clone https://github.com/likelionA-hackathon/likelionA.git
cd likelionA
npm install
copy .env.example .env      # 맥이면 cp .env.example .env
```

`.env` 는 비밀값이 들어가서 깃에 안 올라갑니다.
**clone 받으면 없는 게 정상이고**, `.env.example` 을 복사해서 쓰시면 됩니다.

그다음 `.env` 를 열어서 노션 **command** 페이지의 값 두 줄을 넣어주세요.

```
DATABASE_URL="..."
DIRECT_URL="..."
```

**두 개 다 필요합니다.** 하나만 넣으면 안 돌아갑니다.

마지막으로:

```bash
npm run dev
```

브라우저에서 <http://localhost:3000/api/me> 를 열어 JSON이 나오면 성공입니다.

### 잘 안 되면 — 진단 먼저

```bash
npm run doctor
```

Node 버전, 의존성, `.env` 값, 서버, 데이터까지 순서대로 검사하고
**뭐가 빠졌는지와 뭘 하면 되는지**를 알려줍니다.

> 막혔을 때 "안 돼요" 대신 **이 화면을 캡처해서 팀방에 올려주세요.**
> 원인이 바로 보여서 훨씬 빨리 풀립니다.

## 4. 이것만은 꼭

### ① `npm run db:seed` / `npx prisma db push` 절대 돌리지 마세요

DB를 **다같이 하나** 쓰고 있습니다. 돌리는 순간 데이터가 초기화되고 워크스페이스 ID가
전부 바뀌면서, **나머지 사람 코드가 그 자리에서 다 깨집니다.**
필요하면 제가 단톡방에 공지하고 돌리겠습니다.

### ② `.env` 는 깃에 올리지 마세요

DB 비밀번호가 들어 있습니다. `.gitignore` 에 넣어놔서 신경 안 쓰셔도 되는데,
강제로 `git add` 하지만 말아주세요. 한 번 올라가면 히스토리에 영구히 남습니다.

### ③ `git push -f` 금지

남의 커밋이 사라집니다. 복구가 제일 어려운 사고입니다.

## 5. 깃 사용법

한 레포에 셋이 붙으니 이것만 지켜주세요.

- **작업 시작 전에 `git pull`** — 충돌 사고의 90%가 이걸 안 해서 납니다
- **main에서 바로 작업하지 말고** 본인 브랜치에서 (`feat/이름`)
- **main에 합칠 땐** 단톡방에 한마디 남기고

깃이 처음이시면 [`docs/GIT.md`](GIT.md) 를 보세요.
충돌 났을 때 VSCode에서 뭘 눌러야 하는지까지 적어뒀습니다.

### 레포는 이거 하나로 갑니다

따로 파지 말아주세요. 한 레포라서 **타입을 공유**할 수 있습니다.
제가 API 응답을 바꾸면 두 분 에디터에 바로 빨간 줄이 뜹니다.
레포가 갈리면 이게 안 되고, 합칠 때 처음 만나서 터집니다.
